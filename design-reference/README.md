# Design reference — source of truth

Twee referentie-screenshots (aangeleverd door de eigenaar) zijn leidend voor
het ontwerp van BabyPhone.online. Bewaar de afbeeldingen in deze map:

- `screenshot-1-dashboard.png` — **app/dashboard** (links: Parent Unit met
  icon-sidebar, statusbalk, grote video, dB-audiometer, 5 grote knoppen,
  4 statuskaarten, event log. Rechts: Baby Unit met grote preview,
  statuskaarten, pairing/room code + QR, toggles, functietegels).
- `screenshot-2-homepage.png` — **homepage/landing** (donkere hero
  "Je baby. Altijd dichtbij.", nav rechtsboven, 3 trust-punten, device-mockup,
  grote rolkeuze-card, trustbar, lichte sectie "Gebouwd voor rust en
  vertrouwen", voorbeeldkaarten).

## Kernrichtlijnen
- Naam overal: **BabyPhone.online** (geen "Luna Unit").
- Donker nachtblauw/zwart, warm coral accent, zacht groen success,
  glasachtige cards, grote radius, subtiele borders/glow.
- Prioriteit: eerst visuele overeenstemming met de screenshots, daarna
  functionaliteit. Nette placeholder boven een kapot ontwerp.
